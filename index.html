// What is VERIDIC

Not a Chatbot.
An Agentic OS.

Most AI assistants talk. VERIDIC acts. It's a deterministic operating layer that sits on top of Windows, understanding your voice commands and executing real system actions — opening apps, managing files, tuning hardware, automating workflows — with guaranteed, repeatable outcomes.

Every action is backed by a registered tool with validated parameters. No guessing, no hallucinating file paths, no approximate results. If VERIDIC says it did something, it did.

// Core Features

Engineered for Determinism

Every capability is purpose-built. No black boxes, no unpredictable outputs — just reliable, auditable execution.

Voice-First Control

Wake-word activation with real-time speech recognition. Speak naturally — VERIDIC understands intent, not just keywords. Multilingual support included.

Deterministic Execution

Every action maps to a registered tool with validated parameters. The same command produces the same result every time — guaranteed, auditable, and repeatable.

Transactional File System

Automatic backups before every file operation. Full rollback capability if anything goes wrong. Your data is never at risk.

Digital Twin Sandbox

Run "what-if" simulations before committing changes. Preview the outcome of complex operations in a safe, isolated environment.

Capability Acquisition

VERIDIC can install and configure tools on demand. If it doesn't have a capability, it acquires one — automatically and securely.

Hardware Intelligence

Monitor CPU, GPU, RAM, and thermals in real time. Switch performance modes, manage fan curves, and protect your hardware proactively.

Autonomous Workflows

Define multi-step task chains via simple JSON. VERIDIC executes them autonomously — scheduled, event-triggered, or on voice command.

Security & Permissions

Face ID authentication, granular permission gates, and full audit logging. Every action is traceable and every tool requires explicit authorisation.

Local-First / Offline

Runs entirely on your machine with local LLMs (Gemma via Ollama). Optional cloud fallback for advanced tasks. Your data never leaves your PC.

Persistent Memory

VERIDIC remembers your preferences, past actions, and context across sessions. It learns your patterns without sending data to any cloud.
